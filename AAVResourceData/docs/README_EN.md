# AAV-CCLE Client Delivery Package

This package is prepared for direct client use. It contains only client-facing, usable, and reviewable materials, and excludes internal audit trails, internal decision logs, and internal process records.

## Main Contents

- `data/`
  - AAV sequence table
  - AAV-to-cell-line assay pairing table
  - AAV support-layer table
  - CCLE feature table
- `meta/`
  - Client-facing source manifest
  - Delivery summary
  - Data checksums
- `docs/`
  - Delivery notes in Chinese and English
  - Limitation notes in Chinese and English
  - Process summary in Chinese and English
  - File guide in Chinese and English
  - Package manifest
