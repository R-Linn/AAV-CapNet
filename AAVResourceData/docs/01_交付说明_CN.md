# 交付说明

## 1. 交付目标

本次交付的目标，是基于公开可核验来源，对 AAV 变体信息、AAV 与肿瘤细胞系实验信息以及可关联的 CCLE 肿瘤细胞系特征进行整理、筛选、合并与说明，形成一套可直接使用、可继续扩展、可回溯来源的研究型交付包。

## 2. 已交付内容

### AAV 序列整理表

文件：`data/aav_sequence_base.csv`

主要内容：

- AAV 变体或血清型名称
- full amino acid sequence
- 序列长度
- 证据等级
- 来源类别
- accession / 直接来源核验状态
- 备注说明

### AAV 与细胞系实验配对表

文件：`data/aav_assay_pairs.csv`

主要内容：

- AAV 变体
- 细胞系原始名称
- 规范化细胞系匹配
- 癌种语义
- 实验指标类型
- 原始实验值与单位
- 指标家族
- 可比范围
- 来源文献与说明

### AAV support 层补充数据

文件：`data/aav_fit4function_support.csv`

主要内容：

- 公开 support 层 insertion library 数据
- 与主表分开保留
- 用于支持扩展研究，不混入 full-length 主表完成度

### CCLE 特征整理表

文件：`data/ccle_features.csv`

主要内容：

- 细胞系 ID
- DepMap ID
- 癌种 / 亚型 / 组织来源
- 表达字段
- RPPA 字段
- 当前 release 与单位说明

### 来源与交付摘要

文件：

- `meta/source_manifest_client.csv`
- `meta/delivery_summary.json`
- `meta/data_checksums.sha256`

## 3. 本交付的核心价值

本交付的重点不是简单拼接多张表，而是：

- 只保留公开可核验来源
- 明确每类数据的来源与证据边界
- 对不可直接比较的实验值保留原始语义
- 不对缺失的序列或数值做人为补齐
- 让后续研究、筛选与继续扩展具备清晰起点

## 4. 适用场景

本交付适合用于：

- 研究准备与资料整理
- AAV 变体与肿瘤细胞系资料索引
- AAV × cell line 方向的前期分析底表
- 后续继续扩展公开来源时的基础交付底座
