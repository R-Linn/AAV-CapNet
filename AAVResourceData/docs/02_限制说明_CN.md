# 限制说明

## 1. 来源限制

本交付仅基于公开可核验来源整理。  
如果某一信息在公开来源中没有被明确给出，则不会被人为补齐。

## 2. 实验体系差异

不同论文中的实验体系并不完全一致，例如：

- MOI 或剂量设置不同
- reporter 体系不同
- 时间点不同
- readout 方式不同
- 细胞培养背景不同

因此：

- 某些实验值适合保留在同一表中用于查阅
- 但不代表所有值都可以直接作为严格同量纲横向比较

## 3. 序列完整性限制

并非所有工程化 AAV 研究都公开完整全长序列。  
部分公开资料仅提供：

- parent anchor
- mutation list
- region-level evidence
- barcode / library information
- assay-first 文献记录

因此：

- 并非每条记录都保证具有完整 full-length sequence
- 缺失项会按真实情况标注，不会人为补齐

## 4. support 层数据的边界

`aav_fit4function_support.csv` 为 support 层数据，保留用于支持研究和扩展分析。  
该表不应被理解为 full-length 主表的直接补齐结果。

## 5. 当前成熟度边界

本交付适合作为研究级整合底座，但不应被夸大为：

- 已完全统一量纲的 benchmark 数据集
- 已覆盖全部高价值 engineered AAV 变体
- 已足以单独支撑强统计结论的终局综合 atlas
