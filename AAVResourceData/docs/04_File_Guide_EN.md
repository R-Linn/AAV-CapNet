# File Guide

## data/

- `aav_sequence_base.csv`
  - main AAV sequence table
- `aav_assay_pairs.csv`
  - AAV-to-cancer-cell-line assay pairing table
- `aav_fit4function_support.csv`
  - AAV support-layer table
- `ccle_features.csv`
  - CCLE cancer cell line feature table

## meta/

- `source_manifest_client.csv`
  - client-facing source manifest with public source links, source levels, and notes
- `delivery_summary.json`
  - current delivery snapshot
- `data_checksums.sha256`
  - sha256 checksums for the main delivered data files

## docs/

- delivery notes in Chinese and English
- limitation notes in Chinese and English
- process summary in Chinese and English
- file guide in Chinese and English
- `package_manifest.csv`
  - full file list of this package
